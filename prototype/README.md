# Agent-Toolbox 交互原型

此目录存放用于设计评审和实现对照的静态页面。启动项目后访问 [http://localhost:3000/prototype/](http://localhost:3000/prototype/)，也可在浏览器中直接打开 `index.html`。

| 文件 | 内容 |
| --- | --- |
| [index.html](./index.html) | 主交互原型，包含六个控制台模块 |
| [wireframes.html](./wireframes.html) | 页面线框与布局 |
| [style.html](./style.html)、[styles/index.html](./styles/index.html) | 样式规范与主题预览 |
| [DESIGN-HANDOFF.md](./DESIGN-HANDOFF.md)、[DESIGN-MANIFEST.json](./DESIGN-MANIFEST.json) | 设计交接和源文件清单 |
| [assets/](./assets/)、[styles/shared/](./styles/shared/) | 原型通用样式、脚本和示例数据 |

控制台的 React 实现及数据流见[当前实现](../docs/guides/current-implementation.md)。
