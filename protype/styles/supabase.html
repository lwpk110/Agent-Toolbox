色彩

炭黑 #171717 底，靠 #2E2E2E → #393939 的边框阶梯分层；翡翠绿 #3ECF8E 只做点缀和"运行中"状态，不铺大面积。

字体

标题全部 400 常规字重，不靠加粗；小标签用等宽大写加宽字距。

形态

主按钮是黑底白描边的胶囊形，切换器也是胶囊；几乎没有投影。

适合

偏数据库、网关、基础设施的产品气质，深色下状态绿非常醒目。

字体说明

原规范的 Circular 是商业字体，这里回退到 Helvetica Neue / 苹方；等宽字体 Source Code Pro 是开源字体。
